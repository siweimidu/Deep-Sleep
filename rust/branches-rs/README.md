## `index.cjs` patch (re-apply after `refresh`)

`buildMessageVersions` returns a JS `Map`, and the binary wire path does not revive the `$map`
marker while the JSON path does, so the map arrived as a plain object. `fix-glue.mjs` makes the wire
path revive it too:

```sh
node rust/branches-rs/fix-glue.mjs   # idempotent; `refresh` regenerates index.cjs and drops it
```

`build` keeps the patch; only `refresh` drops it. Same situation as `tolocal-rs`.
